# 작업·코드 템플릿

- [task.md.tmpl](task.md.tmpl): 목표·허용 파일·완료 기준·가설·실제 검증·다음 행동을 작은 작업 단위로 정의한다.
- [python_module.py.tmpl](python_module.py.tmpl): 개요·입출력·오류·부작용을 포함한 Python 코드 시작점. 미구현은 명시적으로 실패한다.
- [js_module.js.tmpl](js_module.js.tmpl): JSDoc을 포함한 JS 함수 시작점. 적용 스택을 확정한 후 사용한다.

템플릿은 서비스 구현·테스트 통과 코드가 아니다. 실제 파일로 복사한 뒤 미구현 부분을 채우고 해당 기능 검증·색인 갱신을 수행한다.
