## 협업 규칙
1. `main`은 항상 실행되는 버전. 직접 push 하지 않아요.
2. 작업은 브랜치에서: `이름/작업내용` (예: `heeyoung/main-screen`)
3. 작업 끝나면 PR → 1명 확인 → 병합
4. 시작 전 `git pull origin main`으로 최신 받기
5. API 키·비밀번호는 커밋 금지. `.env`에 넣고 키 이름만 `.env.example`에 적기
6. 할 일은 이슈로 만들고 Project 보드에서 관리
