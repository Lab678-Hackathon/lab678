03 예상 위험요소 (사전 확인 필요)

🔑
외부 API 키 8종 의존 OpenAI, Supabase, TourAPI, Seoul Culture, KMA, AirKorea, Tmap, Google Places, Naver Maps — 전부 있어야 완전 동작. 키 없이도 graceful degradation이 구현돼 있는가 확인 필요.
🔄
AGENT_LOOP 기본값 false .env.example에 AGENT_LOOP=false로 설정 — 핵심 agentic 루프가 비활성화 상태. true로 켰을 때 실제로 작동하는지 검증 필요.
🗄️
Supabase + RAG pgvector 별도 설정 SUPABASE_DB_URL이 없으면 /api/ask (RAG)만 503. 4개 마이그레이션 SQL이 실제 적용돼 있는지, pgvector 임베딩이 ingested 상태인지 확인 필요.
⏱️
Render free tier cold start 첫 요청 ~30초 지연 — 해커톤 데모에서 치명적일 수 있음. 유료 플랜 또는 다른 배포 옵션 검토 필요.
🌏
서울 특화 데이터 파이프라인 TourAPI는 한국 관광지만 커버. 다른 도시/도메인으로 확장하려면 소스 레이어 전면 교체 필요. "서울 문화경험"에 특화된 플랫폼.
👥
코딩팀 부재 버그 발생 시 대응 공백. orchestrator.py (870줄), agent_loop.py (757줄) 같은 복잡한 파일을 처음 보는 사람이 즉시 수정하기 어려울 수 있음.
✅
강점: 테스트 44개 + 배포 설정 완비 도메인 로직 단위 테스트 존재. render.yaml + vercel.json이 준비돼 있어 새 계정으로 배포는 상대적으로 빠를 것.
