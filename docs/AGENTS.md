# 문서 작업

공통 기준은 [TEAM_WORKFLOW.md](../TEAM_WORKFLOW.md). 재개 시 [현재 상태](development/current-state.md)를 먼저 읽고 필요한 문서만 연다.

- `development/state.json`은 짧은 현재 상태의 편집 원본, `discussion-log.md`는 시점별 경위, `tasks.md`는 작업 목록, `reports/`는 사용자에게 출력한 완료 보고문이다. 승인·제안·미정을 구분한다.
- `planning/`의 첨부 원본과 `reference/`의 과거 브랜치는 참고 자료다. 명시 요청 없이 내용 변경·최신 정책으로 승격하지 않는다.
- 원문 대화의 문자 단위 전사를 자동 확보한 것은 아니다. 중요한 요구·결정·수정·증거·미정은 기록하고 완료 보고문 전체는 그대로 보존한다.
- 매 작업 종료·방향 변경·인계 전에 state와 다음 행동을 갱신한다. 감시기는 state를 렌더링할 뿐 대화를 대신 이해하지 않는다.
