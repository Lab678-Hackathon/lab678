# 대중교통 노선·모바일 경로 카드

2026-10-31 사용자 요청: 지하철 호선/버스 번호 누락 확인, 작은 글씨와 뭉친 정보를 모바일에서 읽기 쉽게 개선. 개인 점검 화면과 백엔드의 보완이며 팀 프론트는 별도 연결이 필요하다.

## 원인과 처리

기존 서버는 카카오 `StepProperties.guidance`만 보존하고 `vehicles`/`stops`를 버렸다. 공식 응답 필드의 차량 이름·정류장 순서를 보존해 표시한다. 새 키나 제공사 변경은 필요하지 않다. [카카오 공식 응답 규격](https://developers.kakao.com/docs/ko/kakaomap/rest-api).

`POST /preview/transit` 기존 필드는 유지하고 `routes[].steps[]`에 아래 선택 필드를 추가했다. 팀 공유 전 담당자 확인용이며, 기존 프론트는 알 수 없는 필드를 무시할 수 있다.

```json
{
  "mode": "SUBWAY",
  "vehicles": [{"name": "1호선", "type": "일반"}],
  "stops": ["청량리(서울시립대입구)", "제기동", "종로3가"],
  "boarding_stop": "청량리(서울시립대입구)",
  "alighting_stop": "종로3가"
}
```

위 JSON은 형식 설명용으로 중간역을 생략한 예시다. 실제 조회 응답 전체가 아니다. 차량 정보가 없으면 `vehicles: []`, 정류장 목록 누락/손상/2개 미만이면 `stops: []`, 승하차는 `null`. 안내문이나 LLM에서 노선·역을 추정하지 않는다. 여러 차량 옵션은 보존하되 같은 노선 이름의 중복 표시는 줄인다.

## 화면과 실행

http://127.0.0.1:8765/ 새로고침 → 나들이 찾기 → 추천 → 행사 선택 → 대중교통 안내 보기.

- 경로 선택 버튼에 실제 노선 조합과 시간/환승을 표시.
- 단계별 카드: 단계·수단 → 큰 노선 이름(24px) → 승차/하차(20px) → 시간·거리(19px) → 원문 안내(18px).
- 버튼 최소48px, 320px부터 한 열 배치. 원문 안내는 줄바꿈하고 데이터는 평문으로 표시.
- 조회시각·미래 출발시각 미적용·전체 도보 미확인은 접힌 확인사항에 유지. 요금/확인 필요는 화면에 표시.
- 텍스트가 기본이며 ‘이 구간 지도 보기’와 ‘텍스트 안내’로 왕복. 제공되지 않은 경로선을 만들지 않는다.

## 실제 확인과 회귀

고정 공개 QA 좌표 청량리역→서울돈화문국악당에서 HTTP200, 3개 경로 확인:

| 수단 | 실제 노선 이름 | 승차 → 하차 |
|---|---|---|
| 지하철 | 1호선 | 청량리(서울시립대입구) → 종로3가 |
| 버스 | 종로12 | 종로3가역9번출구 → 창덕궁 |
| 버스 | 272 | 청량리역환승센터 → 창덕궁.우리소리박물관 |

이는 조회 시점 결과로 고정 추천/운행시간 보장이 아니다. 우대요금·배차·막차·무장애·전체 접근 도보는 검증하지 않았다.

- `python utils/scripts/check_transit_details.py`: 실제 키 조회 1회, 공개 QA 응답만 `.local/transit-details/` 보관. 키 미출력.
- `node utils/scripts/check_transit_mobile.cjs --live`: 모바일320/390/768, 노선/승하차/버튼/가로넘침/지도, 미확인·HTML 평문, 502/늦은 응답, 실제 앱 API 조회 포함6구간 PASS. 첫3구간은 실조회 응답 재생이며 마지막1구간만 API 실호출.
- 기존 `check_transit_ui.cjs --live`: 실제 행사 선택→대중교통→실제 도보 전환, 모의 실패·재시도·0건·취소·선택보존 회귀 PASS.
- 백엔드 전체83개 PASS(대중교통8개 포함). 실제 조회 성공과 모의 예외 검증을 구분한다.

증거: [모바일 검사 결과](qa-transit-mobile/ui-checks.json). 실제 390px 캡처는 `.local/transit-details/mobile-card.png`. 전체 도보량/미래 날짜 반영/팀 프론트 배포는 완료 범위 밖이다.
