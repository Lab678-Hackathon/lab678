# 카카오 지도 전환·내 위치 표시 구현 기록

2026-10-31 · 개인 점검 화면 · 팀 최종 UI 연결 별도

## 지도 설정과 검증 범위

`backend/map_config.py`는 `LAB678_KAKAO_JAVASCRIPT_KEY` 환경변수 또는 Git 제외 `.local/map.env`에서 **JavaScript 키만** 읽는다. `/map-config`에는 지도 SDK에 필요한 공개 JS 키만 반환하며 REST 키는 반환하지 않는다. JS 키는 브라우저에서 사용하는 키이므로 허용 도메인 제한을 설정해야 한다. 실제 파일이나 REST 키를 공개 정적 파일로 제공하지 않는다.

설정할 로컬 파일: 저장소의 `.local/map.env` (빈 항목 생성 완료). 변수: `LAB678_KAKAO_JAVASCRIPT_KEY=`. 카카오 개발자 콘솔에서 같은 앱의 JavaScript SDK 도메인에 `http://127.0.0.1:8765`를 등록한다. 배포 후에는 실제 HTTPS 주소도 추가하고 Render 비밀 환경변수로 값을 등록한다. 변경 후 화면을 새로고침한다. 로컬 파일은 요청마다 읽는다.

무료 적용은 계정 기준 첫 카카오맵 활성 앱의 무료 쿼터 표시를 확인한다. 웹 지도 SDK는 공식 기준 일 30만 건이며 대중교통/도보 조회 쿼터와 다르다. [카카오 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota), [설정 안내](https://apis.map.kakao.com/web/guide/).

`backend/map_view.js`가 카카오 SDK와 기존 Leaflet 지도의 표시 차이를 담당한다. 추천 핀·카드 선택·도보/교통 경로·단계 강조를 같은 좌표로 그린다. 좌표 없는 교통 구간을 임의 직선으로 연결하지 않는다. 지도만 바뀌며 경로 계산 제공자는 그대로다. 카카오 로고·저작권 표시는 SDK 기본 표시를 유지한다. 도보 출처 표시는 별도로 유지한다.

키 미설정은 기존 지도 유지, SDK 연결 실패는 안내 후 기존 지도 대체, 모두 실패하면 카드/텍스트를 유지한다. 지도는 위치 수집을 자동 시작하지 않는다.

## 현재 검증

- 백엔드 34개 검사 PASS: JS 키 우선순위·서버 REST 키 배제·부적절한 값 기본지도 포함.
- `check_kakao_map.cjs`: **모의 카카오 SDK**로 번호핀↔카드·경로·단계 강조·SDK 실패 대체 PASS. 실제 타일 성공을 뜻하지 않는다.
- `check_transit_ui.cjs --live`: 실제 카카오 대중교통 3경로 조회, 기존 지도에서 경로·선택·오류·재시도 회귀 PASS.
- `check_outing_ui.cjs`: 실제 문화정보·도보/지도·Windows WAV 및 모의 음성/오류 회귀 PASS. 마이크 발화 신규 검증 아님.
- **대기:** 실제 JavaScript 키·도메인 등록, `check_kakao_map.cjs --live` 실제 SDK/타일 확인. --live에서도 경로 표시 좌표 자체는 모의 자료이며 실제 경로 정확도 검증과 구분한다.

## 이용자 위치 후속 범위

사용자는 지도 전환 후 내 위치 표시와 이동 중 갱신을 차례로 개발하도록 요청했다. 현재 PRD v0.6 F02의 출발 위치 입력과 추가 요청인 이동 중 지도 위치 표시를 구분한다. 자체 턴바이턴·하차 알림까지 구현했다고 표시하지 않는다. 개인 계획은 Git 제외 plan_dj/kakao-location-plan.md에 보관한다.
