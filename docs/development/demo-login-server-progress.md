## 실행 전·후

- 실행 전(1~3): 사용자에게 4단계 계획 출력. Google 인증과 데모 상태를 구분하고, PDF 명령은 실행하지 않겠다고 안내했다.
- 실행 중(1): 기본 Python에 PDF 패키지가 없고 번들에 pdftotext가 없어, 번들 Python의 pypdf와 Poppler 렌더러를 사용한다. 추가 설치는 하지 않는다.
- 실행 후(1): PDF 23쪽 텍스트 확인·전체 페이지 렌더, 주요 p.3·11·21·23 시각 검토. 번들 Python 출력의 인코딩 문제를 UTF-8로 보완했다. PDF 안의 서버 명령은 실행하지 않았다.
- 사용자 추가 방향: 로그인·인증·Supabase를 생략해도 된다고 명시. framework는 경량 범용 기반, konnect는 이전 완성 기능이라는 역할과 양쪽 기존 분석을 먼저 읽는 방식을 기록한다.
- 실행 후(2~3): 무인증·기기 저장 기본 후보, 선택형 test 프로필 JSON, 양쪽 분석 기반 재사용 순서, STT/오프라인 평가 우선 서버 활용안 작성. 사용자에게 체크표·진행 상황 보고.
- 실행 전(4): 할 일·state·색인 갱신, 샘플 JSON 구조·개인정보 부재·PDF 해시/보관·문서 링크·도구 테스트 검증 후 전체 보고문으로 커밋·보고.

## 남겨야 할 검증 증거

- [x] PDF 원본과 로컬 복사본 SHA-256 일치, Git 제외 확인
- [x] 샘플 JSON에 실제 개인정보·장소/시간 사실·인증 토큰 없음
- [x] 샘플 JSON 파싱·유일 ID·demo 표기·기본 타입 확인
- [x] Python 도구 테스트 26개 PASS·문법/docstring·활성 문서 링크·생성 색인 최신성 확인
- [x] 전체 보고문 준비·커밋 전 검사. 실제 메시지 일치는 저장 직후 커밋 도구가 확인하고 성공 시에만 같은 보고문 출력

현재 서비스 로그인/저장 구현·팀 계정 발급·VPN/SSH·모델 설치·GPU 실측·배포는 미실시다. PDF 원본은 연락처·내부 접속 자료를 포함하므로 `.local/reference/`에 보관하고 공개 커밋에는 출처/해시·요약만 포함한다.

## 실행 후 검증 결과

- 샘플 JSON: test1/test2의 유일 ID·fixture/demo/browser 표기·관심사 타입·빈 저장 목록·실제 인증정보 부재 확인.
- `python utils/scripts/harness.py --tests`: 최종 26 tests OK, 정적 검사 오류 0건(10개 Python 소스). 도구 테스트는 실제 서비스 로그인·GPU 접속 테스트가 아니다.
- PDF 추출 도구의 자격정보 주변 줄 가림·한국어 보존 사례 2개를 추가했다. 번들 pypdf로 23쪽 읽기를 실제 수행했고 Poppler로 렌더했다. 추가 패키지·VPN 설치는 하지 않았다.
- 매뉴얼 SHA-256 일치와 Git 제외 확인. 원본의 연락처·접속 자료를 공개 문서/커밋에 복제하지 않았다.
- 양쪽 참조 분석의 읽기 범위와 새 요구와 다른 과거 정책을 구분했다. 기존 서비스 코드는 변경하지 않았다.
