동조님 점검 화면에 **KONNECT의 홈 → 조건 입력 → 지도·가로 카드** 구성을 반영했습니다. 열어 둔 탭을 새로고침하고 **‘나들이 찾기’**를 누르면 됩니다. [점검 화면 열기](http://127.0.0.1:8765/)

- **입력** — 출발지와 시간을 먼저 보여주고 좌표는 접었습니다. ‘현재 위치 사용’, 직접 좌표 수정, 한국어 음성·텍스트 입력을 지원합니다.
- **결과** — KONNECT의 청록색 선택 표시와 번호 체계를 적용했습니다. 지도 핀과 카드가 같은 번호로 연결되고, 카드는 가로로 넘기거나 ‘이전·다음’으로 이동할 수 있습니다. 운영시간·요금·이용 대상과 ‘추가 확인 필요’를 구분했습니다.
- **검증** — Edge에서 실제 전시 5건 조회, 핀↔카드 선택, 조건 변경·재조회가 통과했습니다. 360px 폭에서 화면 전체가 가로로 밀리지 않는 것도 확인했습니다. 현재 위치와 음성은 모의 입력으로 검증했습니다.

기존 KONNECT 코드·에셋의 직접 이식 허용 범위가 미확인이라, 화면 구조와 동작을 참조해 개인 점검 화면에 새로 구현했습니다. 작업 결과는 `dj/develop`에 로컬 커밋했습니다. [검증 체크표](D:/git/lab678/docs/development/mvp-plan.md)
