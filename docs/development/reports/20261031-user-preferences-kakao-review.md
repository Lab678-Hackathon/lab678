사용자 선호 저장과 카카오 로그인 활용 범위를 확인했습니다.

- 현재 PRD는 체험 로그인과 동일 브라우저의 선호·장소·코스 저장을 요구하며, 실제 OAuth·서버 회원 DB·기기 간 동기화는 MVP 범위 밖입니다.
- 카카오 로그인은 권한과 동의에 따른 계정·프로필 정보 제공에 활용할 수 있습니다. 음악 취향·걷기·예산은 우리 대화에서 파악해야 하며 개인 카카오톡 대화 내용을 가져오는 방식은 지원되지 않습니다.
- 자연어에서 파악한 이번 나들이 조건과 사용자가 확인한 지속 선호를 분리하는 방향을 개인 계획에 기록했습니다. 카카오 로그인 도입은 범위 변경 검토 대상으로 남겼습니다.
- 공식 문서와 PRD를 검토했으며 실제 로그인 연동이나 서비스 코드 변경은 하지 않았습니다. Push는 하지 않았습니다.
