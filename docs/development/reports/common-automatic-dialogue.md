자동 대화와 화면 이동을 로컬 통합 화면에 연결했습니다.

- Chrome http://127.0.0.1:5175/?#/home 에서 ‘자동 음성 대화 시작’을 누르면 AI가 먼저 질문하고 답변 듣기→후속 질문을 반복합니다. 기본 5회/무응답 15초이며 설정에서 변경할 수 있습니다.
- 홈·조건·추천·상세·내 정보에서 같은 대화창을 사용합니다. ‘두 번째 장소 자세히 보여줘’, ‘이 장소 읽어줘’, ‘추천 목록 보여줘’, ‘조건 바꿔’로 현재 후보와 화면을 조작합니다.
- 음성으로 요청한 이동은 대화를 이어가고, 수동 이동·중지·탭 숨김에서는 멈춥니다. 변경 동의는 새로고침과 재시작 후에도 유지하며, 추천은 S02a 최종 확인을 거칩니다.
- 자동 대화 회귀 12구간과 화면 이동 6구간 PASS. 실제 Naito 음악 후속 질문 1회 PASS. 음성 인식·낭독 장치는 모의이며 실제 마이크·스피커는 확인이 필요합니다.
- 8파일 인계 패치 적용·해시 검사와 오프라인 하네스를 확인했습니다. 팀 원본·공용 기획·공개 배포는 미반영이며 코스/길찾기 팀 화면은 연결 중입니다. 로컬 작업 커밋이며 Push는 하지 않았습니다.
