대중교통도 외부 지도로 나가지 않고 앱 안에서 볼 수 있게 했습니다.

- ‘대중교통 안내 보기 → 지도 보기’로 전환하고, 안내 단계를 누르면 해당 구간을 확대합니다.
- 카카오가 반환한 실제 경로 좌표를 사용합니다. 버스는 청록색, 지하철은 보라색, 도보는 회색 점선으로 표시합니다. 좌표가 없는 구간은 임의로 연결하지 않습니다.
- 다른 경로를 선택하면 지도도 바뀝니다. 외부 카카오맵은 ‘외부 지도도 확인하기’에 선택 기능으로 남겼습니다.
- 백엔드 테스트 20개와 개발 도구 테스트 26개 통과. 실제 3개 대중교통 경로와 모바일 크기 화면의 지도 표시, 단계 확대·경로 변경·좌표 누락·오류 처리를 검증했습니다.
- 점검 서버에 적용했습니다. 브라우저에서 Ctrl+F5로 새로고침한 뒤 확인할 수 있습니다. 팀 최종 UI 통합과 원격 push는 아직 하지 않았습니다.
