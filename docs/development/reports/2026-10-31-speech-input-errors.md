기존 화면은 여러 오류를 모두 ‘음성 인식 실패’로 표시했습니다. 브라우저가 알려주는 원인과 오류 코드를 표시하도록 수정했습니다. 동조님 PC에서 처음 실패한 원인은 아직 확인되지 않았습니다.

**화면을 새로고침하고 ‘한 번 말하기’를 다시 눌러 주세요.** 또 실패하면 안내 끝의 괄호 안 코드만 알려주세요. 예를 들어 `audio-capture`는 마이크 입력 장치를 열지 못한 경우이고, `network`는 음성 인식 서비스와 통신하지 못한 경우입니다. [점검 화면 열기](http://127.0.0.1:8765/)

바로 음성으로 계속하려면 **‘더 원하는 게 있으세요?’ 입력칸 → Windows 키 + H → “국악을 듣고 싶어요” → ‘분류 반영’** 순서로 시도해 주세요. Windows 받아쓰기는 인터넷 연결과 작동하는 마이크가 필요합니다. [Microsoft 음성 입력 안내](https://support.microsoft.com/ko-kr/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)

오류 5종을 모의 검증해 기존 문장이 유지되고 입력칸으로 돌아오는 것을 확인했습니다. 변경은 `dj/develop`에 커밋했습니다.
