TourAPI 키는 **공공데이터포털**에서 받으면 됩니다.

1. [한국관광공사 국문 관광정보 서비스_GW](https://www.data.go.kr/data/15101578/openapi.do?recommendDataYn=Y)에 접속해 로그인합니다.
2. **활용신청**을 누릅니다. 활용 목적은 “시니어 문화나들이 서비스의 주변 문화시설 검색 및 추천”으로 적으면 됩니다.
3. 신청 후 **마이페이지 → OpenAPI 활용신청 현황/개발계정**에서 해당 서비스와 승인 상태, **일반 인증키**를 확인합니다. Encoding/Decoding이 함께 보이면 **Decoding**을 복사하세요.
4. [culture.env](D:/git/lab678/.local/culture.env)의 `LAB678_TOUR_API_KEY=` 뒤에 저장하고 알려주세요. 서울시 키는 그대로 두면 됩니다.

서울시 키는 정상 연결됐습니다. 실제 조회에서 **23건을 받아 추천 후보 22건**을 만들었습니다. 검증 기록을 로컬 커밋했으며, Push는 하지 않았습니다.
