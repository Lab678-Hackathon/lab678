동조님이 보신 대로 **말할 시간이 생기기 전에 꺼졌습니다.** 마이크 권한은 허용됐지만 캡처가 **197ms 만에 종료**됐고, 발화 시작(`speechstart`)은 기록되지 않았습니다.

| 버튼을 누른 뒤 | 동조님 화면에서 기록된 내용 |
|---|---|
| 5ms | 마이크 권한 `granted` |
| 160ms | 오디오 캡처 시작 |
| 357~358ms | 캡처 종료 직후 `network` 오류. 엔진 상세 메시지는 비어 있음 |
| 394ms | 인식 종료. 전사 결과 없음 |

**다음 확인은 같은 PC의 Microsoft Edge에서 하는 것이 좋겠습니다.** Edge 주소창에 `http://127.0.0.1:8765/`를 직접 붙여 넣고 **나들이 찾기 → 한 번 말하기 → “국악을 듣고 싶어요”** 순서로 시도해 주세요. 문장이 입력칸에 나타나는지가 성공 기준입니다.

별도 Edge의 가상 마이크 시험에서는 결과 이벤트가 왔지만 문장은 비어 있었습니다. 그래서 **Edge에서 실제 한국어 인식이 성공했다고 볼 수는 없습니다.** 화면에 이벤트별 시간, 권한, 엔진 메시지, 전사 글자 수를 추가하고 빈 전사도 따로 표시하도록 수정·커밋했습니다. Edge에서도 실패하면 **‘진단 복사’** 결과를 보내주세요. 두 환경이 어느 단계에서 달라지는지 비교할 수 있습니다.
