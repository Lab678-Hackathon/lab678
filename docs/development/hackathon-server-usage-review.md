## 2. 추천 활용 순서 [제안]

| 순서 | 활용 후보 | 얻을 가치 | 채택 전 검증 |
|---|---|---|---|
| 1 | **한국어 STT 시험** | 음성 조건 입력의 인식 품질·지연 비교 | 비민감 오디오, 날짜/지명/시간 인식, 무음·실패·동시 요청 |
| 2 | 후보 모델·프롬프트의 오프라인 평가 | 필드 추출·누락 질문 품질, 중복 LLM 호출 감소 근거 | 같은 입력 세트·출력 스키마·호출 수·실측 지연 |
| 3 | 문서 정리·임베딩 등 일괄 작업 | 필요한 경우 자료 전처리 실험 | 자료 필요성·CPU 대비 이점·반출 정책. RAG/DB 도입은 필수 아님 |
| 4 | 작은 대화 모델 추론 비교 | 외부 LLM 대안 가능성 | 실제 자원·라이선스·모델 확보·형식 안정성·서비스 연결 |
| 5 | TTS·지속적인 공개 서비스 | 추가 기능 가능성 | 음성·모델 품질·네트워크·운영 시간이 확보될 때 별도 검토 |

**우선은 STT 실험·평가용 계산 자원으로 쓰는 안을 추천**한다. 지도/문화 API 조회와 결정론 판정, 체험 프로필·브라우저 저장에 GPU가 필수인 구조를 만들지 않는다. GPU를 제공받았다는 이유로 LLM·RAG·Supabase를 모두 도입하지 않는다.

Whisper 계열은 다국어 음성 인식 후보이며, 영어 전용 `.en` 대신 한국어를 다루는 다국어 모델로 실험해야 한다. 품질·속도는 실제 한국어 지명·시간 발화로 측정한다. [Whisper 공식 저장소](https://github.com/openai/whisper)

faster-whisper는 CTranslate2 기반 후보이며, 공식 문서가 GPU 실행의 CUDA/cuDNN 라이브러리 요구사항을 설명한다. 매뉴얼의 `nvidia-smi` 예시 CUDA 값만 보고 설치 호환이 확인됐다고 판단하지 않는다. 기존 허용 가상환경·라이브러리를 먼저 확인하고 임의 드라이버 변경은 하지 않는다. [faster-whisper 공식 저장소](https://github.com/SYSTRAN/faster-whisper)

## 3. 웹 서비스와 연결하는 세 가지 안

### A. 오프라인 개발·평가 자원 — 우선안

로컬 PC에서 허용된 비민감 시험 자료를 전송해 인식/추출 성능을 측정하고 결과를 내려받는다. 공개 배포와 VPN 연결을 분리할 수 있으며 서버 종료 후에도 코드·검증 결과를 로컬 저장소에서 이어갈 수 있다. 녹음·개인정보·민감자료는 매뉴얼의 허용 범위를 확인한다.

### B. VPN이 연결된 시연 PC의 개발 백엔드에서 호출 — 조건부

시연 PC가 VPN을 통해 GPU 서버에 접근하는 사설 시연 경로다. 운영진이 허용하는 서비스 포트·연결 방법을 먼저 확인한다. 로컬 개발 백엔드가 GPU 추론을 호출하고 브라우저는 개발 백엔드와 통신하는 안을 검토할 수 있다. 이는 일반 사용자가 접근하는 공개 데모 URL을 확보했다는 뜻이 아니다. HTTPS·마이크 권한·브라우저 접근 경로도 별도 검증해야 한다.

### C. 공개 웹/API에서 GPU를 호출 — 별도 네트워크 조건 필요

매뉴얼은 공개 HTTPS 게이트웨이나 일반 배포 서버에서 사설망으로 들어오는 경로를 보장하지 않는다. `브라우저 또는 Vercel → 사설 GPU IP`를 기본 구조로 잡지 않는다. CORS 설정만으로 사설망 접근이 생기지 않는다.

운영진이 제공/허용한 게이트웨이·연결 방식이 있으면 그 안에서 검토한다. 임의 터널·외부 공개·ACG/방화벽 변경을 실행하지 않는다. 공개 API의 작업을 내부 worker가 가져오는 구조도 외부 통신·자료 정책·지연·요청 인증 확인이 필요해 해커톤의 첫 흐름을 위한 필수 선택은 아니다.

VPN 설치·OTP·네트워크 조건은 공공존 공식 문서도 참고한다. [NCP 공식 가이드](https://guide-gov.ncloud-docs.com/docs/sslvpn-agent-vpc)

## 4. 승인 후 실제 활용 검증 체크표

- [ ] 팀에 배정된 서버 종류·사설 IP·SSH 포트·계정·VPN/OTP 방법을 안전한 채널로 확인
- [ ] 운영진의 외부 API/모델 다운로드·파일 업로드·서비스 접속 허용 범위를 확인
- [ ] VPN/SSH 접근 확인 후 GPU·CPU·RAM·디스크·Python·설치 라이브러리·모델 캐시 확인
- [ ] 시스템 설정을 바꾸지 않고 허용된 사용자 가상환경 사용 가능 여부 확인
- [ ] 비민감 한국어 STT 사례의 실제 인식·지연·메모리·동시 요청·실패·타임아웃 측정
- [ ] 공개 웹/시연 PC의 접근 경로와 HTTPS·권한·서비스 시간 검증
- [ ] 서버 불가·종료 시 텍스트 입력 또는 검증된 음성 대체 경로로 같은 핵심 흐름 제공
- [ ] 삭제 전 코드·설정 이름·허용 결과·검증 증거를 내려받고 복사/해시 확인

**백업 시점 제안:** 마감 직전까지 기다리지 않고 11/1 오전 중 결과를 확보한다. 구체 시각은 팀 일정과 최신 운영진 공지에 맞춰 정한다. 실제 백업·접속·설치는 이번에 실행하지 않았다.

## 5. 지금 필요한 결정

서버를 실제 배정받았는지, 시연 기기에서 VPN이 가능한지, GPU가 첫 통합의 필수 경로인지부터 확인한다. 제안은 **인증·Supabase 없이 실제 문화정보/지도 흐름을 먼저 연결하고, 제공 GPU는 STT·AI 비용/지연 검증을 돕는 별도 모듈로 검토**하는 것이다. 한국어 대화와 코스 기능을 삭제하는 결정은 아니다.
