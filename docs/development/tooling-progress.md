## 실행 증거·한계

- 실행 환경: Windows PowerShell, Python 3.15.2. 하네스는 9개 Python 소스(도구 8개·테스트 1개)의 문법·docstring과 활성 문서 링크·생성 색인을 검사했다.
- `python utils/scripts/harness.py --tests`: 최종 24 tests OK. 임시 폴더/Git 테스트는 권한 제한 밖에서 실행했다. 실제 서비스·외부 API·음성·지도 화면 검증은 아니다.
- `python utils/scripts/verify_watch.py`: create / content+symbol update / deletion 모두 PASS, 임시 소스 정리.
- `python utils/scripts/catalog.py --find 복사`: reuse.py 한 파일 개요만 출력, 본문 미출력.
- [수정 루프 증거](loops/tooling-index.json): 1차 실패 원인과 2차 통과 기록. 감시기 로그·PID는 `.local/`에만 보관하며 소스 커밋에 포함하지 않는다.
- JS/TS 함수는 정규식 후보 탐색으로 완전성 미보장이다. 현재 실행 코드는 Python이며 미래 JS/TS 실제 구현 시 AST 파서/추가 검증을 결정한다. 토큰 절약률은 측정하지 않았다.
