# 앱 내부 대중교통 안내 진행표

김동조 개인 preview 범위. 공식 API 조사: 2026-10-31. 팀 화면·공통 계약 변경 없음.

## 실행 전 계획

- [x] 기존 외부 카카오맵 대중교통 연결·이동 검토·서버 설정 확인. 사용할 키 없음(값 출력 없음).
- [x] 공식 카카오 대중교통 응답·초/m·환승·도보·요금과 날짜 미지원 확인.
- [x] 개인 서버 연결: 키는 서버 전용, 요청당 한 번·10초 제한·오류/0건 구분.
- [x] 앱 내부 도보/대중교통 전환·경로별 텍스트 안내·외부 지도 선택 연결.
- [x] 모의 응답 테스트와 실제 미설정 구간, 기존 전체 흐름을 구분해 검증.
- [x] 상태·색인·보고문 전체 커밋.

## 실제 연결 선행 조건

사용 가능한 키를 사용자에게 질문한 상태. API 활성화·키·해당 앱 쿼터 확인 전 실제 노선 성공을 주장하지 않는다. 결제나 계정 설정은 변경하지 않는다. 공식 응답에는 출발 날짜·시각 인자가 없어 문화코스 미래 시간 계산에 섞지 않는다. 카카오 대중교통 경로는 우선 내부 텍스트, 지도는 카카오맵 선택 링크로 제공한다.

공식 근거: [대중교통 API](https://developers.kakao.com/docs/ko/kakaomap/rest-api), [이용 안내](https://developers.kakao.com/docs/ko/kakaomap/common).

## 실행 후 검증과 남은 일

- [x] 백엔드 18개 PASS. 초/m·환승·요금·누락/음수/비유한 수·키 미설정·헤더 키만 사용·HTTP 200 오류·인증·429·타임아웃 분리.
- [x] check_transit_ui.cjs: 실제 미설정 응답과 외부 링크/복귀 확인. 정상 경로 2개/이동 단계/도보량/요금·미확인 요금은 **가상 응답으로만** 검증. 실제 도보 전환, 모의 실패/0건/재시도/늦은 응답 닫기 통과.
- [x] 첫 브라우저 검사에서 flex 스타일이 hidden을 덮어 빈 선택 영역이 남는 것을 발견해 전용 hidden 스타일 추가, 전환 재검증 PASS. 고정 헤더도 첫 행만 적용.
- [x] check_outing_ui.cjs 기존 실시간/기록 추천·지도·국악·도보·외부 지도·모의 전사·실제 비무음 WAV 34.2초 회귀 PASS.
- [ ] 카카오맵 활성 앱의 키·쿼터 확인 후 **실제 대중교통 노선 조회**. 실사용 성공이나 미래 일정 반영 완료로 표시하지 않는다.

## 개인 설정과 다음 검증

저장소의 `.local/transit.env`(Git 제외)에 `LAB678_KAKAO_REST_API_KEY=` 값을 직접 채운다. 또는 동일 환경변수를 서버 실행 환경에 설정한다. 파일은 요청마다 읽으므로 저장 후 안내를 다시 열면 반영된다. 채팅·문서·브라우저로 키를 보내지 않는다. 앱 활성화·사용 가능량·과금 여부는 [공식 이용 안내](https://developers.kakao.com/docs/ko/kakaomap/common)에서 확인한다. 이 작업에서 계정·결제·제품 활성화 변경은 하지 않았다.

카드 경로안내 → 대중교통 또는 선택 행사/코스 구간의 대중교통 안내 보기. 내부 텍스트는 공급자 경로 순서 최대 3개, 지도는 카카오맵 선택 링크. 지정 날짜·실제 운행·시니어 우대·접근성 미확인. 원문 경로 저장·자동 재시도·코스 시간 자동 변경 없음.

## 제공사 선택 설명 재검증 · 10/31

- [x] 사용자 제공 ODsay 우선 추천문의 카카오 비공개 전제·무료 수량·OPT 의미 공식 대조.
- [x] 카카오 2026-07-21 공개 API 추가 공지 및 GET /v2/routing/publictraffic 확인.
- [x] ODsay 현행 Basic 일 30회(개인/학생/5인 이하 스타트업), OPT=0 추천/1 유형별 정렬 확인. 월 1,000~3,000회·도보 최적화라는 설명은 근거로 사용하지 않음.
- [x] 사용자 카카오 가입 확인을 상태에 기록. 로그인 앱 가입과 카카오맵 활성화/쿼터 적용은 구분.
- [ ] 실제 앱 권한·키·무료 사용 조건 확인과 공개 장소 1구간 실조회.

판단: 현재 카카오 어댑터/화면이 있으므로 먼저 검증하고 권한/조건/품질이 맞지 않으면 ODsay를 대안으로 검토한다. 이번에는 제공사를 전환하거나 사용자 계정 설정을 변경하지 않았다. 제공된 ODsay 코드에는 타임아웃·HTTP 및 본문 오류 처리 보완도 필요하다.
