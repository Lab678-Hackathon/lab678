# Lab 678 | 손희영 UX/UI 병렬 착수 패키지 v0.1

**기준:** 독립형 PRD v0.5 · 2026-10-30. 디자인 작업용 최소 계약. 화면명세서 완료를 기다리지 않는다. Figma 실제 파일 수정은 아직 실행하지 않음.

## 착수 순서
1. **S01 홈** — 단일 CTA **나들이 찾기**, 저장된 선택/코스 재접근 진입, 체험용 로그인/내 정보 진입. `Plan a route` 별도 CTA 없음. 최초/저장됨/데모 로그인됨 상태 구분.
2. **S02 통합 입력** — 출발 위치(현재 위치/직접 입력), 날짜·시작·종료시각, **더 원하는 게 있으세요?** 텍스트+마이크 버튼, AI의 다음 질문·답변(텍스트)·듣기 상태, 조건 수정·추천받기. 기존 입력과 음성 인식 값은 같은 필드에 표시.
3. **S02a 조건 확인(제안: S02 내 요약/시트)** — AI가 파악한 위치·시간·관심/걷기 선호·제외조건, 부족한 값, 수정/확인. UX/UI에서 별도 화면 필요 여부 제안 가능. 이미 확인한 값 반복 질문하지 않는 흐름.
4. **S03 개별 결과** — **위 지도/아래 가로 카드**; 마커↔카드 포커스; 상태(조건 충족/추가 확인 필요/조건 완화 대안); 장소명/추천 이유/운영·가격·예약·이동·확인 필요; 상세, 장소 선택, **조건 바꾸기**. 결과에 AI 채팅창을 별도 추가하지 않음.
5. **후속 병렬:** S04 장소 상세/임시 선택/저장, S05 코스 2~3곳 순서·시간·지도·수정·저장, S06 체험용 로그인·선호, S07 내 정보.

## 반드시 포함할 상태
- 입력 중/마이크 권한 요청·거부/듣는 중/음성 인식 결과 확인/AI 응답 중/읽는 중/음성 실패·텍스트 대체.
- 추천 중/결과 있음/유효 조건이지만 결과 0건/외부 API 또는 네트워크 오류/가격·예약·이동정보 미확인.
- 결과→**조건 바꾸기**는 S02로 복귀하고 기존 필드값·대화 맥락 유지. 기존 저장된 My Pick·My Route는 자동 변경 금지.
- 저장/개인화는 **체험용 로그인** 안내. 실제 Google/Kakao 인증 화면이나 외부 이동을 시연에 사용하지 않음. 데이터 초기화도 필요.

## 시니어 UX 확인점
- 큰 터치 영역/충분한 대비와 명료한 한국어/기본 텍스트 대체/음성 재생 중단 버튼.
- 걷기 `선호`와 `필수 제한`을 구별하여 표시. 실제 도보·무장애 근거 없으면 확정 문구 금지.
- 카드의 운영·가격·예약·참여 조건과 미확인 안내가 버튼에 가리지 않도록.

## 첫 인계물
Figma S01/S02/S03의 **3개 기본 화면 + S02a/로딩·오류/데모로그인 상태 초안**. 각 화면별 주요 버튼 이름, 누르면 이동하는 화면 ID, 데이터 필요 필드를 Product/Dev에게 전달.

## 팀 확인이 필요한 부분
S02a가 시트인지 인라인인지, 코스 결과 S05의 지도 배치 상세, 시연 기기·화면폭, 실제 지도 API 연결 가능한지. 외부 API 응답이 없어도 기본 프레임은 착수 가능.

**주의:** 기존 디자인 에셋 재사용은 대회 운영진 허용 여부 확인 전 확정하지 않는다. 공통 컴포넌트/파일 소유는 TEAM_WORKFLOW.md 준수.
