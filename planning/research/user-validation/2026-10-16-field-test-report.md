## 01  핵심 요약

- **섭외 시도 7건** 중 **5개 인터뷰 세션** 진행, **참여 불가 2건**(이 중 1건은 영어 소통 어려움). 약 1시간 40분 운영.

- **A 즉시 추천 결과 표시는 5/5세션**에서 확인. A 문화경험 **최종 선택 확인 3세션**(P1~P3). **P4는 진행 중 도움 필요**·최종 완료 여부 미확인, P5는 여러 후보를 탐색했으나 선택하지 않음.

- **B 문화루트 추가 체험은 2세션**(P1 홍대·P3 강남). 두 지역 모두 구현 지원 범위 밖이어서 **별도 안내 없이 기본값 종각**으로 대체되었다고 확인됨.

- 예상보다 섭외와 서비스 반응이 호의적이었음. 희영님 추가 기록에 따르면 **P1은 매우 긍정적으로 평가**하고 **프랑스어 지원을 먼저 요청**했으며, **P2·P3도 B 문화루트에 관심**을 보임. 동시에 Select·Directions 버튼 발견, Select 이후 길찾기, VISITKOREA 외부 이동, 출발지 중복 추천 등 구체적 개선 단서를 확보.

- 10/21 발표 전 변경은 **미확정**. 희영·민규의 **개선 우선 검토 ①~⑤**, **개발 여력 시 ⑥**으로 정리하여 용택님에게 가능 범위 문의 예정.

## 03  현장 모집과 전체 결과

**섭외**  |  **7회 접근**, **5개 세션 성사**, 2건 참여 불가. 1건은 영어 의사소통의 어려움, 다른 1건 사유는 미확인. 현장 체감상 수락과 반응이 예상보다 호의적이었음.

**A 결과**  |  **추천 결과 표시 5/5세션**. **후보 선택 확인 P1·P2·P3**(3건); P4 도움을 받으며 일부 수행/최종 선택 확정 불가; P5 상세 탐색 후 최종 선택 없음.

**상세**  |  P1의 A 선택 장소명은 기록되지 않음. P2·P3는 **명동성당 선택**. P4에서 **남산골 한옥마을**이 출발지와 동일하게 추천됨. 과제 단계와 도움 여부는 구별해 해석.

**B 결과**  |  **2/5세션에서 추가 체험**. P1은 홍대, P3는 강남을 검색하려 했으며 지원되지 않는 지역이 안내 없이 종각으로 바뀌는 경험을 확인.

**유의**  |  숫자는 세션 내 관찰 사실의 단순 집계이며 대표 표본의 성공률·만족도·참여율로 일반화하지 않음.

## 04  참가자별 관찰 기록

### P1 · 프랑스 관광객 (동행인 있음)

A: 추천 결과 확인 및 방문 후보 선택 완료(선택 장소명 미기록). B: **홍대 지역 입력** 시도 → 미지원으로 종각 대체.

관찰: 지도 경로와 실시간 위치 추적에 관심. VISITKOREA 외부 페이지를 상세 탐색했으며 KONNECT로 **복귀할 때 희영님의 도움이** 필요했음.

발언(희영님 추가 확인): 서비스를 직관적이라고 평가했으며, 별도로 지적할 피드백이 없을 정도라는 취지로 **매우 긍정적으로 반응함**. **프랑스어 지원을 참가자가 먼저 요청**하고 서비스 이용 의향도 표현. TikTok 및 ChatGPT 여행정보 활용, 기존 AI 정보 오류 경험 언급. 일부 내용은 프랑스어·한국어 번역기 도움으로 청취.

### P2 · 호주 관광객 커플

A: 추천 결과 확인, 명동성당 선택. 남성 참가자가 주로 조작/응답. 쇼핑·음식에 관심을 나타냈음. **B 문화루트에도 관심**을 보였고, 동행인과 **다음 날 일정을 KONNECT에서 실제 활용해 보려는** 취지로 현장에서 대화를 나눔(**실제 B 조작·루트 생성은 확인되지 않음**).

참고: **쇼핑·음식**은 대화에서 나온 관심으로 기록하며 ‘챗봇 직접 입력’ 사례와 구분.

### P3 · 네덜란드 관광객 부자

A: 아들(사이먼)이 조작, 아버지가 의견 제시. 명동성당 선택. **B: 기능에 큰 관심**을 보였으며, 강남 지역 검색 시도 → 미지원으로 종각 대체.

관찰: 쇼핑 관련 탐색어를 챗봇에 입력. 희영님의 추가 메모에서는 VISITKOREA 외부 페이지를 자세히 살펴본 것으로 기록.

발언: 기존 ChatGPT 등 여행정보와 방문 현장 실제 가격이 달랐던 경험 언급. **추가 언어 지원 희망**도 표현함(구체 요청 언어 미확인). 이는 KONNECT 정보 오류가 검증되었다는 뜻은 아님.

### P4 · 스위스 관광객 (동행 자녀 2명)

A: **남산골 한옥마을**을 Start from으로 설정했는데 **동일 장소가 추천 1순위**로 표시됨. Select 버튼을 찾기 어려워 카드 안 다른 영역을 클릭하는 등 진행 도움 필요. 과제 완료는 △, 최종 선택 여부 미확인.

발언/상황: Naver Map 사용, Google·Instagram·ChatGPT를 여행 정보원으로 언급. **다른 언어로도 서비스가 제공되길** 바란다는 의견을 표현함(구체 요청 언어 미확인).

### P5 · 캐나다 관광객 부부

A: 여러 추천 장소를 자세히 살펴봤으나 하나를 최종 선택하지 않음. 탐색 도중 주 조작자가 배우자에게 기기 조작을 넘겼음.

발언: ChatGPT도 사용하지만 한국 현지 서비스가 더 정확하거나 유용한 경험을 제공하리라는 기대 표현. 실제 우월성 확인이 아닌 참가자 기대 발언으로 기록.

## 05  주요 발견 — 사실·해석의 구분

### F1 · 기본 사용 가능성과 호의적 반응

관찰: A 추천 결과는 5개 세션 모두 표시됨. 3개 세션의 선택 완료가 확인됨. P1은 서비스를 직관적이라고 평가하고 별도의 개선 피드백이 없을 정도라는 취지로 **매우 긍정적으로 반응함**(희영님 추가 기록). **P2는 동행인과 B로 내일 일정을** 실제 활용할 가능성을 이야기했고, **P3도 B에 큰 관심**을 보였음. 직접적인 부정적 평가보다는 전반적으로 호의적인 반응이 많았음.

해석: 초기 탐색 흐름의 유용성을 시사하지만 참가자 모두가 완전하게 자율 수행했다는 뜻은 아님. 사용성 문제는 별도로 존재.

### F2 · Select 및 Directions의 발견 가능성

관찰: 일부 사용자가 Select·Directions를 스스로 찾기 어려워함. 희영님이 Directions 위치를 알려준 뒤 실제로 버튼을 누른 사례가 있음. 정확한 영향 참가자 수는 미확인.

팀 제안(희영): Select 버튼 크기·라벨 가시성 개선, Directions 강조 및 지도 아이콘 추가, **Select 이후 최종 화면**에도 길찾기 동작 제공.

### F3 · 외부 상세정보 이동과 복귀

관찰: P1은 VISITKOREA 페이지에서 오래 머물러 복귀 안내가 필요했으며, P3도 외부 사이트 상세 탐색이 관찰됨. 외부 사이트 체류 자체가 곧 실패라고 단정하지 않음.

협의안(희영·민규): 메인 행동 ‘상세 보기’를 강조하되 외부 서비스명도 안내. 임시 문구는 정확히 **‘See details(VisitKorea)’**. Official website 아래에 배치하고, 선택 완료 화면에서는 VISITKOREA 링크 제거 또는 축소를 검토.

### F4 · 출발지와 동일한 문화경험 추천

관찰: P4에서 Start from=**남산골 한옥마을**인데 추천 1순위도 남산골 한옥마을. 해석: 출발지와 실제 방문 대상의 중복 처리 정책/로직 확인 필요. 위치가 가깝다는 이유만으로 다른 후보를 제외하는 방식은 지양.

### F5 · B 지원 권역 밖 입력의 무안내 대체

관찰: P1 홍대·P3 강남 입력 시 지원 대상 밖이라는 안내 없이 기본 지역 ‘종각’으로 대체됨. B는 A보다 개발 고도화가 덜 된 상태라는 팀 배경 설명이 있음.

제안: **지원하지 않는 지역**이라는 메시지 표시 → A의 Start from 빠른 선택 장소 중 B에서 실제 지원되는 후보 제공 → 사용자가 **직접 재선택**. 날짜·시간 등 기존 조건 유지. 개발 가능성은 미확인.

### F6 · 정보 신뢰성과 추가 관광 수요

관찰: P1·P3에서 **기존 AI 여행정보의 부정확성** 경험 언급, P5에서 현지 서비스에 대한 신뢰 기대. 이는 KONNECT의 정보 정확성을 검증한 근거가 아님.

관찰: P1·P3는 쇼핑 관련 내용을 챗봇에 입력했으며, P2는 쇼핑·음식을 대화에서 언급. 언어 면에서는 **P1이 프랑스어 지원을 먼저 요청**했고, **P3(네덜란드)·P4(스위스)**도 다른 언어 제공을 희망했음(구체 요청 언어 미확인).

해석: 현재 문화경험 중심 MVP 밖의 **쇼핑·음식**, 다국어, 실시간 지도 추적은 향후 확장 후보. 명동 조사 지역이 쇼핑·음식 관심에 영향을 주었을 가능성을 고려.

## 06  개선 요청·검토 우선순위 (희영·민규 협의)

**우선 개선 요청 / 기술 검토 (1~5)**

1. Select 버튼 크기·글자·대비와 발견 가능성 개선.

2. **기존 Directions** 버튼 강조 및 지도 아이콘 추가.

3. Select 이후 최종 선택 화면에도 Directions 제공.

4. VISITKOREA 링크를 **‘See details(VisitKorea)’**로 잠정 수정, Official website 아래 배치, 선택 완료 화면에서는 링크 제거/축소 검토.

5. **A 즉시 추천: 출발지**와 동일한 장소가 추천되는 문제의 원인 확인 및 중복 처리 개선.

**개발 여력에 따라 검토 (6)**

6. **B: 지원 범위 밖** 출발지 입력 시 종각 무안내 대체 방지, 미지원 안내 및 사용자가 B에서 가능한 출발지 직접 선택.

상기 1~6은 팀이 협의한 ‘요청·검토 순위’이며 개발/디자인 반영 확정이 아님. 구체 구현과 일정은 용택님·희영님 협의 후 결정. 동명의 별도 ‘개선 과제 · 개발 가능성 협의안’ 참조.

## 07  검증 한계 및 증빙 취급

- **대표 페르소나**는 미국인 자유여행객이지만 실제 제품 타깃은 서울을 방문하는 다양한 국적의 FIT. 이번 5세션은 프랑스·호주·네덜란드·스위스·캐나다 관광객이며 미국 국적 미확보를 핵심 결함으로 보지는 않음.

- 영어 우선은 팀의 대응 역량 및 관광객 접근성에 대한 초기 가정. 영어 소통이 어려워 참여하지 못한 사례가 있어 다국어 접근성 확대 검토의 참고가 됨.

- 현장 **소규모·편의 표집**, 명동 지역 편향, 커플/가족 공동 참여, 일부 참가자별 과제 완료·선택 장소 기록 부족. 참가자 표현은 메모 요약이지 축어 인용이 아닐 수 있음.

- 첫 세션 일행과 기념사진 촬영이 있었음. 공개 발표·외부 공유용으로 얼굴이 보이는 사진을 사용하려면 별도의 공개 동의 확인 필요. 원본 기록에서는 개인 식별 정보 최소화.

## 08  후속 조치 및 상태

□ 희영·민규: 현장 관찰·발언 사실과 팀 개선안을 구분해 팀에 공유.

□ 용택님: 1~5 우선 검토 항목의 구현 가능성·범위·필요 시간 회신; 6은 여력 시 검토.

□ 팀: 반영/보류/향후 과제를 결정하고 수정 후 핵심 경로 재검증.

□ 발표 준비: 사용자 검증에서 확인된 사실만 사용하고 과제 완료/관찰 한계 및 미완료 개선 상태를 함께 표기.
