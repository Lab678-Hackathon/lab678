## 디자인에서 신경 쓴 것
0. Low-fi → 최종: 9/29 초안은 단순한 그래픽과 강한 색 대비(보라). 실제 서울을 그림처럼 담은 일러스트와 청록으로 더 따뜻하고 친근하게
1. 메인 이미지: 사진 시안은 피로감이 있어 나무, 하늘, 도시를 부드러운 서울 일러스트로 사용
2. 장소 사진: 일러스트로 통일하고 싶었지만 AI 가공 시간 대신 공식 사진을 그대로 써서 속도와 신뢰를 우선
3. 지도: 3D 지도를 표현하기에 시간적 제약, 3D로 주요 아이콘 표시 ,
4. 3D 걷는 사람 아이콘은 지도가 실시간 움직일때 방향이 어긋 날 수 있어, 3D 얼굴 + 핀으로 바꿈
